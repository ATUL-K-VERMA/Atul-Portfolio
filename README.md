# 🚀 AI-Portfolio

# 📖 Overview

**AI-Portfolio** is a modern, responsive portfolio website developed to showcase my expertise as an **AI & Machine Learning Engineer**. The website highlights my professional experience, technical skills, AI/ML projects, certifications, achievements, and contact information through an elegant glassmorphism interface with interactive animations.

Built using **Flask**, **HTML5**, **CSS3**, **JavaScript**, and **Three.js**, the portfolio provides an engaging and responsive user experience across desktop and mobile devices.

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/ATUL-K-VERMA/AI-Portfolio.git
```

Navigate to the project

```bash
cd AI-Portfolio
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
python app.py
```

Open your browser:

```
http://127.0.0.1:5000
```
